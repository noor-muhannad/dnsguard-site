ما تعلّمناه أثناء بناء DNSGuard

النموذج حفظ النطاقات وحالة الحروف

أعطى النموذج الأول اسم تسريب واضحاً بحروف صغيرة درجة 0.000، لأنه تعلّم أن «الحروف الكبيرة = هجوم» وحفظ أسماء النطاقات الخمسة عشر. الحل: خصائص تقرأ الجزء الفرعي فقط ولا تتأثر بحالة الحروف.

الاسم وحده لا يعمّم

بعد حذف الاختصارات، كشف نموذج خصائص الطلب 0% من 5 أدوات من أصل 9 عند حجبها عن التدريب.

1. خصائص الاسم: الجزء الفرعي فقط

نقسم الاسم إلى النطاق المسجَّل (خادم المهاجم) والجزء الفرعي (مكان البيانات). كل الخصائص تُحسب على الجزء الفرعي بحروف صغيرة.

هذا يمنع النموذج من حفظ أسماء نطاقات المهاجم، ومن تعلّم أن «الحروف الكبيرة = هجوم»، وهما الاختصاران اللذان وجدناهما في النسخة الأولى.

dnsguard_features.py 
def split_name(q):
    labels = [l for l in q.strip().rstrip('.').split('.') if l]
    k = 3 if '.'.join(labels[-2:]).lower() in MULTI_TLD else 2   # e.g. edu.iq
    dom = '.'.join(labels[-k:]).lower()   # registrable domain = attacker's server
    sub = '.'.join(labels[:-k])           # subdomain = where the data hides
    return dom, sub, labels

def lexical(q):
    dom, sub, _ = split_name(q)
    s = sub.replace('.', '').lower()      # subdomain only, case-insensitive
    longest = max(sub.lower().split('.'), key=len)
    return {
        'sub_len': len(s),
        'sub_entropy': entropy(s),                       # randomness
        'max_sub_label_len': len(longest),               # DNS limit: 63
        'is_hex_label': int(len(longest) >= 16 and set(longest) <= HEX),
        'is_b32_label': int(len(longest) >= 16 and set(longest) <= B32
                            and any(c.isdigit() for c in longest)),
        'bigram_ratio': english_bigram_ratio(s),         # do letters form words?
        'digit_letter_switch': switches(s) / max(len(s) - 1, 1),
        # ... 18 features in total
    }

2. الحساب الحي: نوافذ زمنية متحركة

في الشبكة يصل كل طلب لوحده، فنحتفظ بنافذة لكل نطاق (آخر دقيقة) ولكل جهاز مع نطاق (آخر ساعة)، مع مجاميع جارية تُحدَّث بخطوة واحدة لكل طلب.

الطريقة نفسها تُستخدم في التدريب بشكل دفعي، وتحققنا أن الطريقتين تعطيان أرقاماً متطابقة 100%.

class _Win:                         # sliding window, O(1) per query
    def add(self, ts, vals, horizon):
        self.dq.append((ts, vals))
        for i, v in enumerate(vals):
            self.sums[i] += v
        while self.dq and self.dq[0][0] <= ts - horizon:   # expire old events
            _, old = self.dq.popleft()
            for i, v in enumerate(old):
                self.sums[i] -= v

def update(self, qname, ts, client):
    f = lexical(qname)
    dom, sub, _ = split_name(qname)
    new = 0.0 if sub in self.seen[dom] else 1.0            # never-seen subdomain?
    D = self.dom[dom];        D.add(ts, (1.0, f['sub_len'], new), 60)      # last minute
    S = self.sess[(client, dom)]
    S.add(ts, (1.0, f['sub_entropy'], f['sub_len']), 3600)                 # last hour
    f['dom_newsub_ratio_w'] = D.sums[2] / D.sums[0]   # ~100 % in exfiltration
    f['cs_mean_entropy_1h'] = S.sums[1] / S.sums[0]   # session average (rate-free)
    return f

3. التقسيم الواعي بالتسرّب

بدل التقسيم العشوائي، نوزّع النطاقات كاملة: النطاق يكون إما في التدريب أو في الاختبار، ولا يكون في الاثنين.

وعند ترك أداة خارج التدريب نحذف أيضاً كل نطاقاتها من التدريب، حتى لا يكون النموذج قد رآها عبر أداة أخرى.

def domain_split(df, seed):
    # no registrable domain may appear in both train and test
    tr, te = [], []
    for y in (0, 1):
        s = df[df.y == y]
        i, j = next(GroupShuffleSplit(1, test_size=0.3, random_state=seed)
                    .split(s, groups=s.domain))
        tr += list(s.index[i]); te += list(s.index[j])
    assert not set(df.loc[tr, 'domain']) & set(df.loc[te, 'domain'])
    return np.array(tr), np.array(te)

4. عتبة الإنذار GCT

نقسم بيانات التدريب حسب النطاق (GroupKFold)، فيُقيَّم كل صف بنموذج لم يرَ نطاقه. ثم نختار العتبة بحيث لا تتجاوز نسبة الطلبات السليمة فوقها الهدف (0.1%).

هكذا تُقاس الإنذارات الكاذبة على نطاقات «جديدة» قبل الوصول إلى الشبكة الحقيقية. الحد الأدنى 0.5 والأعلى 0.99، فلا تجعل GCT النظام أكثر تساهلاً، ولا تطلب يقيناً تاماً.

dnsguard_training_v4 · القسم 5.1 
def oof_scores(X, y, groups, k=4):
    # each row is scored by a model that never saw its domain
    oof = np.full(len(y), np.nan)
    for a, b in GroupKFold(k).split(X, y, groups):
        oof[b] = make_model().fit(X[a], y[a]).predict_proba(X[b])[:, 1]
    return oof

def gct_threshold(X, y, domains, target_fpr=0.001):
    benign = oof_scores(X, y, domains)[y == 0]
    thr = np.quantile(benign, 1 - target_fpr)   # 99.9 % of unseen benign stays below
    return float(np.clip(thr, 0.5, 0.99))

6. شبكة CNN تقرأ الاسم حرفاً حرفاً

تتحول حروف الجزء الفرعي إلى أرقام، وتمرّ على ثلاثة مرشحات بأطوال 3 و5 و7 حروف تلتقط أنماط الترميز، ثم طبقة تعطي احتمال التسريب.

تتدرب على الـ GPU، وكشفت ترميز Base64 الذي لم تره أبداً بنسبة 72% على اسم من مقطعين.

VOCAB = "abcdefghijklmnopqrstuvwxyz0123456789-_."   # 128 chars max

class CharCNNNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.emb = nn.Embedding(len(VOCAB) + 2, 32, padding_idx=0)
        self.convs = nn.ModuleList(
            [nn.Conv1d(32, 64, k, padding=k // 2) for k in (3, 5, 7)])
        self.head = nn.Sequential(nn.Linear(192, 64), nn.ReLU(),
                                  nn.Dropout(0.2), nn.Linear(64, 1))

    def forward(self, x):                    # x: (batch, 128) character ids
        e = self.emb(x).transpose(1, 2)
        h = torch.cat([torch.relu(c(e)).max(dim=2).values for c in self.convs], 1)
        return self.head(h).squeeze(1)       # logit of "exfiltration"

From Audit to Deployment: Leakage-Aware Detection of DNS Exfiltration over Plaintext and Encrypted DNS

من التدقيق إلى النشر: كشف تسريب البيانات عبر DNS العادي والمشفّر بتقييم واعٍ بالتسرّب

نقدّم تقييماً واعياً بالتسرّب لكشف تسريب البيانات عبر DNS العادي والمشفّر. يبيّن التدقيق أن 98.9% من صفوف CIC-Bell-DNS-EXF-2021 مكررة، وأن النماذج تصل إلى السقف الذي يفرضه تضارب التصنيف. وينخفض F1 في DoH من 1.000 إلى 0.94 عند حجب خوادم كاملة، ونبيّن أن ضبط العتبة المعتاد يفشل على الخوادم الجديدة بينما يلتزم GCT بميزانية الإنذار الكاذب. ثم نبني DNSGuard، وهو نظام قابل للنشر يجمع ثلاثة نماذج مع سياسة إنذار تراعي شهرة النطاق وتجمّع الإنذارات، فيكشف 98.6% أو أكثر من كل أداة تسريب لم يرها، مع إنذارين كاذبين فقط من أصل أكثر من 50 ألف زوج سليم.
